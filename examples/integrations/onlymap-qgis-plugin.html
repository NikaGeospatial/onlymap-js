From QGIS project to web map.

QGIS2WebMap turns a finished QGIS project into one interactive HTML file. Send someone your map — not your QGIS project — with no account, web server or coding required.

01

Install

Install QGIS2WebMap from the official QGIS plugins directory, then open it from QGIS.

02

Export

Export your layers, styling and map settings to a single OnlyMapJS HTML file with panning, popups and layer switching.

03

Publish

Double-click the file to open it locally, or deploy it to GitHub Pages and any other static host.

Why use this workflow?

QGIS remains the authoring desk. OnlyMapJS provides the lightweight, shareable browser output — online or offline.

Good fit for

  • Cartographers who already work in QGIS
  • Static sites and hosted project pages
  • Maps that need to travel without a GIS desktop
