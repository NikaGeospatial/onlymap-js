OnlyMapJS examples

Each page below is a real, runnable manifest — open it, pan/zoom/click around. They import the library straight from source, the same way dev/index.html does, so they always reflect the current implementation.

Widgets

Legend, zoom-controls, scale-bar, and a live Vega-Lite chart that updates as you pan.

Responsive widget manager

An interactive v0.4.4 test bench for per-side auto-fold drawers, map-width breakpoints, fold="never", hide-all, clustering, and RTL placement.

Behaviors & overlays

Click a region for a rich popup, hover a point for a tooltip, and drive a layer's filter with a slider.

Basemap

Free basemap presets (OpenFreeMap, CARTO, OSM) with live switching — layers and camera survive the swap.

Columnar data

A week of real USGS earthquakes from an Arrow IPC file — same $field manifest, zero row objects on the render path, apache-arrow lazy-loaded on first use.

Time series

A month of public-domain USGS earthquakes explored through a moving 48-hour window, with a temporal slider, playback, GPU filtering, and synchronized statistics.

GeoTIFF / COG

Real 38 m elevation over the Grand Canyon, streamed from a Cloud-Optimized GeoTIFF by Range request through the native COGLayer — min/max restretch and colormap swaps are GPU uniforms (no tile refetch), nodata filters to transparent, and the legend renders the ramp automatically.

CityJSON

A real 3DBAG tile — CityJSON 2.0, quantized vertices, compound CRS EPSG:7415, LoD 2.2 semantic surfaces — drawn either as true per-face geometry or as extruded footprints with derived eaves/roof/ridge heights. CityJSONSeq streams in as it downloads.

Measure

Geodesic distance and area straight off the map — haversine lengths, spherical-excess areas, live per-segment labels, and a metric/imperial/nautical toggle.

Draw

Sketch points, lines and polygons directly on the map with the draw toolbar — captured into a live layer and saved as a local GeoJSON file, no backend.

3D models

GLB models instanced on the basemap via ScenegraphLayer — the browser half of an IFC/CAD asset pipeline, no three.js required.

Scene lighting

Extruded buildings under the lighting* attributes — the native lighting widget swaps presets and tunes ambient/sun/azimuth live; a sun-date button drives a solar-position sun. Every change is undoable.

Terrain

The keyless AWS terrarium DEM raises Yosemite in 3D; vector layers drape onto the surface automatically, with per-layer drape/offset/off control and live exaggeration.

Google 3D Tiles

Google Photorealistic 3D Tiles rendered through Tile3DLayer. Requires a browser-restricted Map Tiles API key.

3D Flyby

A story-driven Google Photorealistic 3D Tiles flyby across nearby places, with dwell time to inspect tile loading and LOD refinement.

BIM sample

A real IFC medical-dental clinic (2,626 elements) via BIMLayer — per-element picking, isolate/hide/ghost, and colour-by-property on a model parsed straight from the .ifc file, no pre-conversion step.

Live AIS

A live WebSocket ship feed (simulated, aisstream.io format) — upsert-by-key, throttled flushes, widgets updating per flush.

Fleet (polling)

Drivers from an auth-protected REST snapshot endpoint, re-polled with refresh="1s" — the Grab-style transport, with configureData supplying the bearer token.

Map story

A guided tour as a manifest: om-story steps fire the same actions behaviors use, with a player widget, seek/scrub, and pause-on-grab.

React adapter

The programmatic front-end as React components: OmMap, OmLayer, OmWidget, OmOverlay, and useOmMap().
